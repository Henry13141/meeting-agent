# 云文档可选接入

第一步完成本机配置、录音、转写、模型问答和本地纪要保存。云文档是否接入、接入哪套软件，按会议人员的实际使用情况确定。

先了解已有软件与企业账号、纪要给谁看、是否共同修改、保存到哪里、由谁确认正式版本，再核对接口和估算开发。飞书、钉钉、腾讯文档、WPS、企业微信配套文档及其他系统都是待核对选项，当前版本没有通用的“一填地址即可同步”。

少量使用可以导出本地文件后手动上传。重复操作较多时，再开发确认后创建或更新云文档的连接器，保留真实文档地址与回执。需要持续跟进任务时另定任务台账与反馈入口，生成文档本身不代表任务闭环。

模型、文档和任务系统授权分别处理。尚未选定平台时继续本地保存。

**大白话：** 大家已经用什么软件，就先研究怎样沿用。可以先导出文件，确有必要再开发自动同步；不用为选平台耽误本机试用。
